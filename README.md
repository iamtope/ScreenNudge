# ScreenNudge

Monorepo for **pull** — an iOS anti-doomscrolling / Screen Time app — and its marketing website.

| Folder | What it is | Stack |
|--------|-----------|-------|
| [`pull/`](pull/) | The mobile app | Expo / React Native (iOS, Screen Time / Family Controls) |
| [`web/`](web/) | The marketing website (About · FAQ · Contact, 7 languages) | Next.js (App Router, TypeScript) |

## Working on each project

```bash
# The website
cd web && npm install && npm run dev      # http://localhost:3000

# The app
cd pull && npm install && npm run ios      # requires Xcode + an iOS 16.4+ target
```

Each folder has its own `README` with details.

## Deploying the website

`web/` deploys to **Vercel**. Because this is a monorepo, set the project's **Root Directory**
to `web` when importing. See [`web/README.md`](web/README.md#deploy).

## Notes

- Secrets (`pull/.env`, any `.env.local`) are gitignored and are **not** in this repo — set them
  up locally / in your host's environment variables.
- The app's native `ios/` and `android/` folders are generated by Expo prebuild and are gitignored.
